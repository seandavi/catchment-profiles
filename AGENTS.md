# AGENTS.md

- Static site: `index.html`, `style.css`, `js/*.js`, GitHub Pages from `main` root. No framework, no build, no bundler.
- Dependencies come from a CDN at exact versions (DuckDB-Wasm in `js/db.js`, topojson-client and us-atlas in
  `js/map.js`). Pin exact versions; never `latest`.
- SRI: `index.html` has no CDN `<script>`/`<link>`. The us-atlas JSON is fetched with `integrity` (sha384, in `js/map.js`; recompute when
  the version changes). The DuckDB-Wasm and topojson `+esm` ES-module imports and the DuckDB worker/WASM bundles have no SRI: static
  `import` takes no hash, `+esm` output is generated by jsDelivr (not a stable file), and the worker loads via `importScripts`.
- Data contract: a Cancer Basemap release (`<DATA>/manifest.json` + Parquet). Read tables with `read_parquet` on
  manifest paths; never `ATTACH cancerbasemap.duckdb` (its views hard-code URLs). Filter on `source`,
  `source_release`, `measure_id`, `geo_id`.
- `data/catchment/` is a stopgap copy of `catchment.*`; delete it with the fallback in `js/db.js` once a release
  carries them.
- A cell whose `value_status` is not `reported` shows its status label, never a number.
- Pure helpers (no DOM, no CDN imports) live in `js/lib.js` and are tested with `node --test`. Measures live in `js/config.js`.
- Not a clone of Cancer InFocus: do not copy its code, text or assets.
- Headless check: serve the app and a release (README), open `?data=...&center=11`; `window.__cp` holds timings and `query()`.
